### Subscribe to All Processes

Source: https://github.com/its-a-feature/mythic/blob/master/jupyter-docker/jupyter/MythicExamples/Processes.ipynb

Subscribes to real-time updates for all processes across all hosts connected to the Mythic server. The loop breaks after the first data packet.

```python
# ################ Subscribe to processes ################
async for data in mythic.subscribe_all_processes(mythic=mythic_instance):
    print(data)
    break
```

### Subscribe to New Processes

Source: https://github.com/its-a-feature/mythic/blob/master/jupyter-docker/jupyter/MythicExamples/Processes.ipynb

Subscribes to newly created processes. This can optionally be filtered by host and has a configurable batch size.

```APIDOC
## subscribe_new_processes (host, batch_size)

### Description
Subscribes to newly created processes, optionally filtered by host.

### Parameters
#### Path Parameters
- **mythic** (object) - Required - The Mythic instance object.
- **host** (string) - Optional - The hostname to subscribe new processes from.
- **batch_size** (integer) - Optional - The number of new processes to retrieve in each batch.

#### Query Parameters
None

### Request Body
None

### Response
#### Success Response (200)
- **resp** (object) - Description of the new process event data.

### Response Example
```json
{
  "example": "new_process_data"
}
```
```

### Configure Mythic Docker Networking

Source: https://github.com/its-a-feature/mythic/blob/master/Mythic_CLI/Changelog.md

Allows setting `mythic_docker_networking` to `bridge` or `host` for all main Mythic services.

```bash
mythic_docker_networking=bridge
```

```bash
mythic_docker_networking=host
```
