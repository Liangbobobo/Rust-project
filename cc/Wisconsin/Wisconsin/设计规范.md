## 函数结束时的栈内存物理擦除
在 x86_64 汇编与操作系统内核层面,函数退出时，CPU 仅仅执行了一条指令：`add rsp, 0x24xx; ret；`.CPU 只是把栈顶指针 RSP往上挪了位置，物理内存（RAM）中的数据根本没有被擦除，依然 100%原封不动地留在栈底（Stack Slack Space / Dead Stack）
当 Agent 随后进入 Sleep 休眠时，现代 EDR（如 CrowdStrike Falcon、Defender
  for Endpoint）或内存取证工具（如 Moneta、Process Hacker、MiniDump
  转储分析）：
  直接扫描该线程的栈内存，就能把你刚才探测过什么目录、看到了什么文件名全部抓住
因此必须实现栈内存的物理擦除
```rust
 #[inline(always)]
    pub fn zeroize_slice(buf: &mut [u8]) {
        for byte in buf.iter_mut() {
            unsafe {
                core::ptr::write_volatile(byte, 0);
            }
        }
    }
```
