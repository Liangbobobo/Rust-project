通过检查protocol.rs中定义的结构体和官方文档的区别,完善用到的结构体.用到时再检查就行

传输文件和内存数据的关键区别在于 full_path 字段：
文件传输（写入磁盘）
{
  "download": {
    "total_size": 1048576,
    "full_path": "/var/tmp/archive.bin",  // ← 提供完整路径
    "host": "WORKSTATION-7",
    "filename": "archive.bin",
    "is_screenshot": false
  }
}

内存数据（不写磁盘）
{
  "download": {
    "total_size": 1048576,
    "full_path": "",  // ← 空字符串或省略
    "filename": "data.bin",
    "is_screenshot": false
  }
}

Agent 是否报告 full_path 决定了 Mythic 如何追踪该文件。如果 full_path 为空，Mythic 认为文件传输仅存在于内存中，未触及磁盘
